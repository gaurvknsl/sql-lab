# Changelog

## 2.0.0

- Add a DSA mode with 40 questions across five rounds, following the Trees and
  Graphs syllabus: 25 C function exercises and 15 written traces.
- Compile and grade C functions against multiple input cases, with compiler
  feedback and execution timeouts.
- Cover recursive/iterative/level-order traversal, tree operations, BSTs,
  expression/threaded trees, AVL rotations, Red-Black properties, graph
  representations, DFS, BFS, connected components, and spanning trees.
- Keep DBMS and DSA progress separate and retain all 107 DBMS exercises.
- Add a portable Windows package with `start.exe`, bundled Python, and TinyCC.
- Add automated package builds, release publishing, and 66 behavioral tests.

## Earlier versions

- Add the hospital assignment round using the assignment's sample data.
- Introduce the local SQL and PL/SQL practice website and cross-platform tests.
